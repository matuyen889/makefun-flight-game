PolyGlider 3D is an original, complete 3D flight simulation game crafted for desktop web browsers. It runs entirely offline from local static files without any external dependencies or network requests.

## Features
- **Aviation HUD**: Realistic pitch ladder, artificial horizon, airspeed tape (knots), altimeter tape (feet), and magnetic compass rose.
- **Flight Dynamics**: Complete aerodynamic simulation including pitch, roll, yaw, throttle, dynamic lift, induced drag, and gravity.
- **Procedural 3D World**: Low-poly island archipelago, runway with approach lighting and threshold markings, and glowing aerial checkpoint rings.
- **Dual Camera Angles**: Switch smoothly between immersive cockpit first-person view and third-person chase camera.
- **Web Audio Soundscape**: Procedurally generated jet turbine whine, afterburner rumble, and checkpoint chimes via Web Audio API.

## Controls
- **W / S**: Pitch Down / Pitch Up
- **A / D**: Roll Left / Roll Right
- **Q / E**: Rudder Yaw Left / Right
- **Shift / Ctrl**: Increase / Decrease Throttle
- **C**: Toggle Camera Mode (Chase / Cockpit)
